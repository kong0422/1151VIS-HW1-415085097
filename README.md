## 台灣縣市氣象色塊圖

以 **Vue 3.5 + D3.js + TopoJSON** 製作的台灣縣市氣象地圖，每個縣市依「轄內測站的平均值」直接填上顏色，可切換氣溫、紫外線、降雨機率。
資料取自中央氣象署開放資料平台。

### 指標切換

上方按鈕可切換地圖底色所代表的指標：

| 指標 | 色階 | 說明 |
|---|---|---|
| 氣溫 | 藍（冷）→ 黃 → 紅（熱），0–35 °C | 縣市內測站平均 |
| 紫外線 | 依氣象署分級的 5 色：低量級（0–2）、中量級（3–5）、高量級（6–7）、過量級（8–10）、危險級（≥11） | 優先使用「今日最大值」 |
| 降雨機率 | 白 → 深藍，0–100 % | 36 小時預報最近一個時段 |

**累積雨量**（當日，mm）與**日照時數**（小時）目前只顯示在提示窗，不出現在切換按鈕。若想改成按鈕，把 `METRICS.acc` 與 `METRICS.sun` 裡的 `tipOnly: true` 拿掉即可。

### 提示窗

滑鼠移到縣市（或點擊縣市）會出現提示窗，內容為：

- 縣市名稱
- 天氣（圖示 + 文字）
- 氣溫、紫外線、降雨機率、累積雨量、日照時數

### 右側排行

依目前選擇的指標，列出各縣市平均值由高到低的排行。

### 天氣圖示

圖示使用 emoji，不需額外載入圖片。依天氣現象文字對應：

| 天氣文字（範例） | 圖示 |
|---|---|
| 晴 | ☀️ |
| 晴時多雲、多雲時晴 | 🌤️ |
| 多雲 | ⛅ |
| 陰 | ☁️ |
| 陰有雨、陰短暫雨 | 🌧️ |
| 多雲時晴短暫雨（含「雨」且含「晴」或「多雲」） | 🌦️ |
| 含「雷」 | ⛈️ |
| 含「雪」 | 🌨️ |
| 含「霧」 | 🌫️ |
| 其他 | 🌡️ |

### 即時資料

- 開啟頁面時自動抓取，之後每 **10 分鐘**更新一次。
- 也可以按「載入即時資料」手動更新。

## 資料來源與欄位

以下資料集皆來自[中央氣象署氣象資料開放平臺](https://opendata.cwa.gov.tw)。

| 資料集 | 用途 | 使用的欄位 |
|---|---|---|
| `O-A0003-001` 現在天氣觀測報告（每 10 分鐘更新） | 氣溫、累積雨量、日照時數、天氣現象、測站對照 | `AirTemperature`、`Now.Precipitation`、`SunshineDuration`、`Weather`、`StationId`、`StationName`、`GeoInfo.CountyName`、`ObsTime.DateTime`；`UVIndex`（即時讀數，作為紫外線的備援） |
| `O-A0005-001` 紫外線指數－每日最大值 | 紫外線（主要來源） | `weatherElement.location[].StationID`、`UVIndex`；`weatherElement.Date` |
| `F-C0032-001` 36 小時天氣預報 | 降雨機率、天氣現象（補觀測缺漏的縣市） | `PoP`（降雨機率）、`Wx`（天氣現象），取最近一個時段 |
